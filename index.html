T6

Estrategia

Cómo encaro cada proyecto: una carrera dividida en tandas, con una parada en boxes entre cada una.

  1. Descubrir

    Entender el negocio, a quién le sirve el sistema y qué restricciones tiene.

  2. Diseñar

    Modelo relacional, contratos de API con OpenAPI y una arquitectura que se pueda mantener.

  3. Desarrollar

    Código claro y seguro: consultas preparadas, contraseñas cifradas y buenas prácticas.

  4. Desplegar

    Pruebas con PHPUnit y Postman, configuración fuera del código y despliegue documentado.

  5. Mejorar

    Escuchar a quienes usan el sistema y mejorar lo que más les cuesta.
